Your second brain

An assistant that remembers you. Setup takes about 10 minutes. Just follow the steps — you don't need to know anything about computers.

1

Open Terminal

Press ⌘ Cmd + Space, type Terminal, press Enter. A window with text opens — that's normal.

2

Copy this line and paste it into Terminal

bash "$(find ~/Downloads ~/Desktop ~/Documents -maxdepth 5 -name install-mac.command 2>/dev/null | head -1)"

Click in the Terminal window, press ⌘ Cmd + V, then Enter.

If the Mac asks "Terminal would like to access files in your Downloads folder" — click Allow.

Didn't work? Type bash and a space, drag the file install-mac.command from this folder into Terminal, press Enter.

3

Answer the questions

It asks before installing each program. Type y and press Enter each time. For the language, type a number.

  Install Obsidian - shows your notes nicely, free? [y/n] y
 Which language should it speak with you?
   1 - English    2 - Russian    3 - Hebrew    4 - other
  Type a number and press Enter: 1
It may ask for your Mac password. You won't see the letters as you type — that's normal. Type it and press Enter. The first time it may also install Apple's developer tools: this can take 5–15 minutes. Leave it running.
4

VS Code opens — meet your assistant

If it asks "Do you trust the authors of the files in this folder?" — click Trust Folder & Continue.

Click the orange spark ✳ at the top right. The "Chat" panel on the right is Microsoft Copilot, not Claude — close it.

Sign in with your Claude account (Pro or higher), then type hi. It explains everything else — by voice.

5

Talk instead of typing (optional)

Wispr Flow — the most accurate; free 2,000 words a week. On first start it asks for the microphone and accessibility — allow both.

Mac dictation — no limit: turn it on once in System Settings → Keyboard → Dictation, then press the microphone key on the top row.
