# Remember

1. Decide what exactly to save from the conversation. If the user named it, save that.
2. Pick the place (see the table in AGENTS.md): a decision on one question → `Topics/`; a source → `Notes/`;
   the user's own story or raw thought → `Inbox/` word for word; a rule about how to work with them → `My rules.md`.
   If a fitting note exists, update it instead of making a new one.
3. Write in the user's language. Link related notes with `[[Note name]]`.
4. Add one line to `00-Log.md`; for a new note, one line to `00-Index.md`.
5. Answer in one line: what you saved and where, in plain words.
