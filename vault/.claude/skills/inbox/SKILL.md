# Inbox

1. List `Inbox/`. For each item decide: a topic, a source note, a rule, a task for `00-Focus.md`, or keep as is.
2. Never shorten the raw item. Your summary goes to the new note and links back to the raw one.
3. Ask the user only when an item could mean two different things — one question at a time.
4. Log line in `00-Log.md`, index line for each new note.
5. Tell the user in two or three sentences what you sorted and what is left.
