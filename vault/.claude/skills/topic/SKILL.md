# Topic

1. Find all notes about the question (search the folder; read only what matches).
2. Write or update `Topics/<the question>.md`: the short answer first, then who/what says what with links
   `[[Note]]`, then what we chose and why, then when to revisit.
3. Keep it short — topics are read often.
4. Log line and index line. Tell the user the short answer in two sentences.
