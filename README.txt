SECOND BRAIN - an assistant that remembers you
==============================================

>>> Easiest: double-click "START HERE" in this folder. It opens in your browser with pictures. <<<

What you need
- A computer with Windows 10/11 or a Mac.
- A Claude account with a paid plan (Pro or higher) - you sign in yourself.
- Internet. About 15 minutes.

WINDOWS
1. Unzip this folder (right-click the zip -> Extract All).
2. Double-click "install-windows.cmd".
   If Windows shows a blue "Windows protected your PC" window:
   click "More info", then "Run anyway". It shows this for any script from the internet.
3. Answer Y or N for each program. Choose your language.
4. When VS Code opens: "Trust Folder & Continue", then the orange spark icon at the top right, sign in, say "hi".

MAC
1. Unzip this folder (double-click the zip).
2. Open Terminal (Cmd + Space, type "Terminal", Enter).
   Type  bash  and a space, then drag "install-mac.command" from the folder into the Terminal window.
   Press Enter.
3. Answer y or n for each program. It may ask for your Mac password.
4. When VS Code opens: "Trust Folder & Continue", then the orange spark icon at the top right, sign in, say "hi".

Talking with your voice
- Wispr Flow: free 2,000 words a week, then it stops until the weekly reset.
- Built-in dictation has no limit - keep it as backup:
  Windows: Win + H.
  Mac: turn on once in System Settings -> Keyboard -> Dictation, then press the Microphone key
  on the top row (or Edit -> Start Dictation).

Is it safe?
- The installers are plain text - open them in Notepad/TextEdit or ask Claude
  "what does this file do?" before running.
- Programs are downloaded from their makers (Microsoft winget / Homebrew), not from this zip.
- Your notes stay in Documents/SecondBrain on your computer. Nothing is sent to the person who gave you this.
- The assistant cannot delete files and asks before anything outside your notes.

Only take this folder from the person who set it up for you - not a copy forwarded by someone else.
